# Melon Gallery

Melon Gallery 是一款面向 macOS 的本地图片浏览器，适合快速浏览文件夹中的照片、筛选和整理图片，并在需要时查看 RAW 原图。

## 主要功能

- 网格浏览图片，支持缩略图大小调整和顺滑滚动。
- 支持递归扫描子文件夹。
- 支持搜索、排序、收藏筛选和最低评分筛选。
- 支持单选、多选、范围选择、全选和右键操作。
- 支持收藏、评分、复制到文件夹、在 Finder 中显示和移到废纸篓。
- 支持幻灯片播放。
- 支持预览窗口缩放、拖动、1:1 实际大小和九宫格辅助线。
- 支持查看图片信息和 EXIF 元数据。
- 支持两张图片并排对比，可同步或独立缩放、拖动，也可以交换左右位置。
- 支持 Panasonic RW2 文件：先显示内嵌预览，点击“解析 RAW”后再加载完整 RAW。
- 自动识别同名 RAW/JPEG 配对，可在预览中切换或直接对比。
- 最近打开和收藏文件夹可直接移除。
- 缩略图和 RAW 解码采用缓存与按需加载，减少长时间浏览时的内存占用。

## 系统要求

- macOS 14 或更高版本。
- Apple Silicon 或 Intel Mac 均可使用。

## 快速开始

如果项目中已有构建好的应用，可以双击 `dist/Melon Gallery.app`，或在终端运行：

```sh
open "dist/Melon Gallery.app"
```

从源码构建并启动：

```sh
./script/build_and_run.sh run
```

只构建应用包：

```sh
./script/build_and_run.sh build
```

构建需要 Xcode 16+ 或包含 Swift 6 工具链的环境。

## 基本使用

1. 点击工具栏中的文件夹按钮，选择图片文件夹。
2. 如果需要扫描子文件夹，打开“递归扫描”。
3. 点击图片进行选择；按住 `Shift` 可选择范围，按住 `Command` 可增减选择。
4. 双击图片或按 `Return` 打开预览。
5. 在图片上右键，可以执行收藏、评分、复制、查看 Finder、幻灯片和删除等操作。

删除操作会将文件移到 macOS 废纸篓。多选删除会先显示确认提示。

## 图片筛选和排序

工具栏中的搜索框可以按文件名搜索。筛选菜单提供：

- 显示或隐藏 RAW 文件。
- 仅显示收藏图片。
- 按最低评分筛选。
- 清除所有筛选条件。

点击排序按钮可以选择名称、拍摄日期、修改日期或文件大小；点击排序按钮本身可以切换升序和降序。

## 预览窗口

预览工具栏提供以下操作：

- “适应窗口”：让图片完整显示在当前窗口中。
- `1:1`：按实际解码像素查看图片。
- 加号和减号：调整缩放比例。
- 九宫格按钮：显示或隐藏构图辅助线。
- 信息按钮：显示图片元数据。
- RAW 按钮：对 RW2 图片执行完整 RAW 解析。

在“Melon Gallery → 设置”中可以开启“打开图片时最大化预览窗口”。开启后，预览窗口会占满当前屏幕的可用区域，同时保留菜单栏和 Dock；图片仍会按比例完整显示。

预览窗口中可以使用方向键切换图片，按空格关闭普通预览或暂停幻灯片，按 `Esc` 关闭窗口。

## 双图对比

选中两张图片后，点击工具栏中的“双图对比”，或使用 `Command + Shift + C`。

对比窗口支持：

- 同步或独立缩放和拖动。
- 适应窗口和 `1:1` 实际大小。
- 九宫格辅助线。
- 交换左右图片。
- 对 RAW/JPEG 配对图片直接对比。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开文件夹 | `Command + O` |
| 选择全部图片 | `Command + A` |
| 打开预览 | `Return` |
| 开始幻灯片 | `Command + Space` |
| 双图对比 | `Command + Shift + C` |
| 移到废纸篓 | `Delete` |
| 网格中移动选择 | 方向键 |
| 扩展范围选择 | `Shift` + 方向键 |
| 关闭图片预览 | `Esc` 或空格 |
| 关闭双图对比 | `Esc` |

## 支持的格式

普通图片：JPEG、PNG、GIF、HEIC、WebP、TIFF、BMP。

其他：PDF、Panasonic RW2。

GIF 和 WebP 动图在预览中按动画方式显示；RAW 文件默认可以隐藏，需要在筛选菜单或设置中打开“显示 RAW 文件”。

## 隐私和文件安全

Melon Gallery 只读取和处理本地文件，不会上传图片。收藏、评分、最近打开和显示偏好保存在本机。复制图片会生成副本，删除图片会使用 macOS 废纸篓机制，便于恢复。

## 开发验证

运行测试：

```sh
swift test
```

如果设置了真实 RW2 样本目录，还可以运行完整 RAW 测试：

```sh
MELON_RW2_SAMPLE_DIR="/path/to/rw2-samples" swift test
```
